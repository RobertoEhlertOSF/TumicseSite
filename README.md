# TUMICSE Site

Site institucional e área administrativa do Templo de Umbanda Mãe Iansã e Caboclo Sete Estrelas.

## Stack

- ASP.NET Core MVC
- Razor Views
- ASP.NET Core Identity
- EF Core
- SQL Server
- Hospedagem alvo: MonsterASP.NET

## Objetivo

Criar uma landing page pública para apresentação do terreiro, área protegida para médiuns acessarem aulas em vídeo, CRUD de eventos e painel administrativo.
